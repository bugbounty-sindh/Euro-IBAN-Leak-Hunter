> World's first Open Source tool to find leaked European IBANs on GitHub. Built for Security Researchers & Bug Bounty Hunters.

### ⚡️ What is this?
This tool hunts for accidentally leaked IBANs (International Bank Account Numbers) of European countries like Germany (DE), France (FR), Italy (IT), Spain (ES) etc.

Companies pay $$$ for finding such PII leaks!

### 🎯 Features
- Supports 20+ European Countries
- Validates IBANs with MOD97 algorithm
- No false positives
- Lightweight & Fast
